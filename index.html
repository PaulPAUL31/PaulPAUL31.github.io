Conception d’un benchmark qui mesure la qualité des LLM open-source quand on les interroge sur du français médical.

  • 500questions-réponses
  • 100comptes rendus cliniques
  • 19spécialités médicales

Un jeu de référence construit à partir de comptes rendus cliniques du corpus PARHAF, pour poser aux modèles des questions dont on connaît la bonne réponse.

  • 18LLM open-source comparés
  • H100GPU chez Scaleway

Inférence de tous les modèles avec vLLM sur GPU H100 (Scaleway), dans les mêmes conditions pour que la comparaison soit équitable.

  • vLLM
  • Scaleway
  • OVH

Un moteur de scoring à trois niveaux, du plus mécanique au plus proche du jugement humain.

  1. Métriques lexicales et sémantiques

    La réponse ressemble-t-elle à la référence, dans les mots et dans le sens ?

    • ROUGE-L
    • BLEU
    • BERTScore (CamemBERT-bio)
    • SemScore (BGE-M3)

  2. Factualité médicale

    Les bonnes entités médicales sont-elles présentes ? Pipeline de reconnaissance d’entités alignée sur les terminologies de santé, enrichie d’un dictionnaire de près de 3 400 synonymes.

    • DrBERT-CASM2
    • IAMsystem
    • UMLS
    • SNOMED
    • CIM-10
    • BDPM

  3. LLM-as-a-judge

    Un modèle Qwen, hébergé sur OVH/Scaleway, évalue chaque réponse comme le ferait un relecteur.

    • Qwen
    • Prompt engineering

Une application web NiceGUI pour exploiter les résultats sans toucher au code :

  • classement général des modèles
  • comparaison tête-à-tête entre deux modèles
  • analyse par spécialité médicale
  • gestion des datasets et recalcul des scores

Le tout livré avec tests unitaires et documentation.

  • NiceGUI
  • Python
  • Tests unitaires
